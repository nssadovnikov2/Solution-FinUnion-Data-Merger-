# Владение данными

| Сущность | Data Owner | Data Steward | Producer (создатель) | Consumer (потребитель) | Правила изменения | Правила качества |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Клиент** | Руководитель розничного блока | Data Steward по клиентским данным | FU CRM, RB CRM (через MDM) | FU Core, RB Core, FU Loans, RB Loans, DWH, BI, Мобильное приложение | Только через MDM Customer Hub. В CRM изменения синхронизируются с MDM (CDC). | 100% заполнение ФИО и ИНН; валидация паспортных данных; проверка дублей по ИНН/паспорту; уникальность master_id. |
| **Счет** | Руководитель департамента учёта | Data Steward по счетам | FU Core, RB Core | FU Cards, RB Cards, DWH, BI, Регуляторная отчётность | Только через Core Banking. Запись изменения баланса — через транзакции. | 100% заполнение номера счёта, типа, валюты; проверка соответствия суммы остатка сумме транзакций (daily reconciliation). |
| **Карта** | Руководитель карточного бизнеса | Data Steward по картам | FU Cards, RB Cards | FU Core, RB Core, DWH, BI, Мобильное приложение | Только через Card Processing System. | Маскирование номера при отображении; проверка статуса карты; валидация срока действия. |
| **Кредитный договор** | Руководитель кредитного бизнеса | Data Steward по кредитам | FU Loans, RB Loans | FU Core, RB Core, DWH, BI, Регуляторная отчётность | Только через Loan System. Изменение статуса договора — через кредитные операции. | 100% заполнение суммы, ставки, срока; проверка графика платежей; сверка остатка с транзакциями. |
| **Транзакция** | Руководитель департамента учёта | Data Steward по транзакциям | FU Core, RB Core, FU Cards, RB Cards | DWH, BI, Регуляторная отчётность, Антифрод | Только через Core Banking или Card Processing. | 100% заполнение суммы, даты, счетов; проверка валютного контроля; сверка итогов за день. |
| **Обращение клиента** | Руководитель контакт-центра | Data Steward по обращению | FU CRM, RB CRM | MDM (для профиля), DWH, BI | Только через CRM. | 100% заполнение клиента и даты; классификация темы и категории; проверка закрытых статусов. |
| **Продукт (справочник)** | Руководитель продуктового офиса | Data Steward по продуктам | MDM Reference Data | FU Core, RB Core, FU Loans, RB Loans, DWH, BI | Только через MDM. | Уникальность кода продукта; проверка актуальности тарифов; версионирование изменений. |
