# Мастер-системы

| Сущность | Источники As-Is | Мастер-система (3 мес.) | Целевая мастер-система (12 мес.) | Связь с BIAN | Обоснование |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Клиент** | FU CRM, RB CRM | **MDM Customer Hub** (золотая запись) | **MDM Customer Hub** (золотая запись) + FU CRM (операционная запись) | Party Data Management | Клиенты дублируются в двух CRM. MDM обеспечивает дедупликацию, создание единого ID и распространение золотой записи во все системы. В целевом состоянии FU CRM остаётся источником операционных данных, но MDM остаётся мастером для идентичности. |
| **Счет** | FU Core, RB Core | **FU Core** (временно, для счетов FU) + **RB Core** (для счетов RB) | **FU Core** (единый) | Current Account / Account Management | Счета — финансовые данные. В целевом состоянии все счета мигрируют в FU Core. В промежуточном состоянии обе системы остаются источниками для своих счетов, но через интеграционный слой формируется единый справочник счетов. |
| **Карта** | FU Cards, RB Cards | **FU Cards** (временно) + **RB Cards** (временно) | **FU Cards** (единый) | Payment Card / Card Management | Карточный процессинг — специализированная система. В целевом состоянии все карты переводятся в FU Cards. В промежуточном состоянии обе системы работают параллельно с синхронизацией через интеграционный слой. |
| **Кредитный договор** | FU Loans, RB Loans | **FU Loans** (временно) + **RB Loans** (временно) | **FU Loans** (единый) | Loan Management / Consumer Loan | Кредиты мигрируют в FU Loans. В промежуточном состоянии обе системы работают параллельно с синхронизацией остатков и статусов. |
| **Депозит** | FU Core, RB Core | **FU Core** (временно) + **RB Core** (временно) | **FU Core** (единый) | Deposit Account / Savings Account | Депозиты мигрируют в FU Core. |
| **Продукт (справочник)** | FU Core, RB Core (разные справочники) | **MDM Reference Data** | **MDM Reference Data** | Product Catalog / Product Management | Справочники продуктов должны быть едиными для всей группы. MDM обеспечивает версионирование, маппинг и распространение единого справочника. |
| **Транзакция** | FU Core, RB Core, FU Cards, RB Cards | **FU Core** (для транзакций FU) + **RB Core** (для транзакций RB) | **FU Core / FU Data Lake** (единый) | Transaction Management / Payment Execution | Транзакции — финансовые данные. В целевом состоянии все транзакции консолидируются в FU Core и архивируются в Data Lakehouse. |
| **Обращение клиента** | FU CRM, RB CRM | **FU CRM** (временно) + **RB CRM** (временно) | **FU CRM** (единый) | Customer Interaction / Service Engagement | Обращения должны быть видны в едином профиле клиента. В целевом состоянии RB CRM выводится, обращения мигрируют в FU CRM или в новый сервис взаимодействий. |
| **Справочник (общий)** | Разрозненные справочники в FU и RB | **MDM Reference Data** | **MDM Reference Data** | Reference Data Management | Справочники отделений, тарифов, категорий клиентов, кодов операций должны быть едиными. MDM обеспечивает централизованное управление. |
| **Договор (обобщающий)** | FU Core, RB Core | **FU Core** (временно) + **RB Core** (временно) | **FU Core** (единый) | Agreement Management | Договоры мигрируют в FU Core как головная система для всех договорных отношений. |
| **Операция / Платеж** | FU Core, RB Core | **FU Core** (временно) + **RB Core** (временно) | **FU Core** (единый) | Payment Order / Payment Initiation | Платежи мигрируют в FU Core. |
