# Ключевые бизнес-сущности

Перечень бизнес-сущностей предметной области, их определения и атрибутный состав.

1.1. Клиент (Customer / Party)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Физическое или юридическое лицо, взаимодействующее с банком. Центральная сущность, вокруг которой строятся все остальные. |
| **Основные атрибуты** | Клиентский ID (master), ФИО/Наименование, ИНН, СНИЛС, паспортные данные (серия, номер, дата выдачи, орган), дата рождения/регистрации, телефон, email, адрес регистрации, тип клиента (физлицо/юрлицо), сегмент, статус (активен/закрыт). |
| **Связи** | Связан с: Счет, Карта, Кредитный договор, Депозит, Обращение, Транзакция. |
| **Системы-источники** | FU CRM, RB CRM (основные), FU Core, RB Core (вторичные). |
| **Критерий включения** | Центральная сущность; без неё невозможны остальные бизнес-процессы. |
| **Проблемы качества** | Дублирование клиентов в FU CRM и RB CRM; разные идентификатори (FU_ID vs RB_ID); несовпадение ФИО и паспортных данных по одному клиенту; разные форматы телефонов и адресов. |

1.2. Счет (Account)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Банковский счет клиента, на котором хранятся денежные средства. Может быть текущим, расчетным, накопительным и т.д. |
| **Основные атрибуты** | Номер счета, тип счета (текущий, расчетный, накопительный), валюта, остаток, дата открытия, дата закрытия, статус (активен/заблокирован/закрыт), процентная ставка, владелец (Клиент). |
| **Связи** | Связан с: Клиент (владелец), Карта (привязана к счету), Кредитный договор (счет для погашения), Депозит (счет для начисления), Транзакция (дебет/кредит). |
| **Системы-источники** | FU Core, RB Core (мастер-источники). |
| **Критерий включения** | Ядро банковского учета; без счетов невозможны операции. |
| **Проблемы качества** | Разные модели счетов в FU Core и RB Core (структура, нумерация); несовпадение остатков при миграции; разные статусы счетов. |

1.3. Карта (Card)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Платежная карта клиента, привязанная к счету. Может быть дебетовой или кредитной. |
| **Основные атрибуты** | Номер карты (маскированный), тип (дебетовая/кредитная), статус (активна/заблокирована/просрочена/закрыта), дата выпуска, дата истечения срока, платежная система (Visa/Mastercard/Мир), лимит (для кредитных карт), счет-источник. |
| **Связи** | Связан с: Счет (привязка), Клиент (владелец), Транзакция (операции по карте). |
| **Системы-источники** | FU Cards, RB Cards. |
| **Критерий включения** | Основной инструмент розничного бизнеса. |
| **Проблемы качества** | Разные статусы карт в FU и RB; разные тарифы и лимиты; дублирование карт при миграции. |

1.4. Кредитный договор (Loan Agreement)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Договор кредитования между банком и клиентом. Содержит условия предоставления, погашения и обслуживания кредита. |
| **Основные атрибуты** | Номер договора, тип кредита (потребительский, ипотека, автокредит), сумма, валюта, процентная ставка, срок, дата выдачи, дата погашения, статус (активен/просрочен/закрыт), график платежей, остаток задолженности. |
| **Связи** | Связан с: Клиент (заемщик), Счет (для погашения), Транзакция (платежи по кредиту). |
| **Системы-источники** | FU Loans, RB Loans. |
| **Критерий включения** | Ключевой продукт розничного бизнеса. |
| **Проблемы качества** | Разные правила кредитных продуктов (ставки, графики, штрафы); несогласованные остатки задолженности; разные статусы договоров. |

1.5. Депозит (Deposit)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Депозитный договор клиента с банком. Клиент размещает средства на определенный срок под процент. |
| **Основные атрибуты** | Номер договора, тип депозита (срочный, накопительный, до востребования), сумма, валюта, процентная ставка, дата открытия, дата окончания, статус (активен/закрыт). |
| **Связи** | Связан с: Клиент (владелец), Счет (начисление процентов). |
| **Системы-источники** | FU Core, RB Core. |
| **Критерий включения** | Значимый продукт розничного бизнеса. |
| **Проблемы качества** | Разные модели депозитов; разные ставки; несовпадение сумм при миграции. |

1.6. Продукт (Product)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Справочная сущность, описывающая банковские продукты (кредитные, депозитные, карточные, страховые). |
| **Основные атрибуты** | ID продукта, название, тип (кредит, карта, депозит, страховка), тарифы, условия, ограничения, период действия. |
| **Связи** | Связан с: Кредитный договор, Депозит, Карта (продуктовая линейка). |
| **Системы-источники** | FU Core, RB Core, справочные системы (не синхронизированы). |
| **Критерий включения** | Необходима для единой продуктовой линейки и управления тарифами. |
| **Проблемы качества** | Разные справочники продуктов в FU и RB; несинхронизированные тарифы и условия; разные названия одних и тех же продуктов. |

1.7. Транзакция (Transaction)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Операция по счету или карте клиента (пополнение, списание, перевод, платеж). |
| **Основные атрибуты** | ID транзакции, тип (приход/расход), сумма, валюта, дата/время, счет-источник, счет-назначения, карта (если есть), статус (проведена/отменена/в обработке), описание. |
| **Связи** | Связан с: Счет (дебет/кредит), Карта (карточная операция), Клиент (участник). |
| **Системы-источники** | FU Core, RB Core, FU Cards, RB Cards. |
| **Критерий включения** | Ядро финансового учета и отчетности. |
| **Проблемы качества** | Разные форматы транзакций; дублирование операций при миграции; расхождения в суммах; разная классификация транзакций. |

1.8. Обращение клиента (Customer Interaction)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | История взаимодействия клиента с банком: звонки, чаты, письма, визиты в офис, претензии. |
| **Основные атрибуты** | ID обращения, тип (звонок, чат, письмо, визит), тема, описание, дата/время, статус (открыто/в работе/закрыто), категория (претензия, консультация, запрос), результат. |
| **Связи** | Связан с: Клиент (автор обращения), Сотрудник (обработавший). |
| **Системы-источники** | FU CRM, RB CRM. |
| **Критерий включения** | Важна для клиентского опыта и анализа качества обслуживания. |
| **Проблемы качества** | Дублирование обращений; разные категории и статусы; потеря истории при миграции. |

1.9. Сотрудник (Employee)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Сотрудник банка, взаимодействующий с клиентами и системами. |
| **Основные атрибуты** | ID сотрудника, ФИО, должность, подразделение, роль, права доступа, контакты. |
| **Связи** | Связан с: Обращение (обработчик), Клиент (закрепленный менеджер). |
| **Системы-источники** | FU CRM, RB CRM, HR-системы. |
| **Критерий включения** | Необходим для RBAC и отслеживания ответственности. |
| **Проблемы качества** | Разные справочники должностей; дублирование сотрудников при слиянии. |

1.10. Договор (Contract / Agreement) — обобщающая сущность
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Обобщенная сущность для всех видов договоров (кредитных, депозитных, расчетно-кассового обслуживания). |
| **Основные атрибуты** | Номер договора, тип (кредитный, депозитный, РКО), дата заключения, статус, стороны (Клиент, Банк). |
| **Связи** | Связан с: Клиент, Счет, Продукт. |
| **Системы-источники** | FU Core, RB Core, FU Loans, RB Loans. |
| **Критерий включения** | Обобщает все договорные отношения. |
| **Проблемы качества** | Разные модели договоров в FU и RB; несогласованные статусы; разные нумерации. |

1.11. Справочник (Reference Data)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Систематизированные справочные данные: список отделений, тарифов, продуктов, категорий клиентов, кодов операций и т.д. |
| **Основные атрибуты** | Код справочника, значение, описание, дата актуальности, версия. |
| **Связи** | Используется всеми основными сущностями (Клиент, Счет, Продукт и т.д.). |
| **Системы-источники** | FU Core, RB Core, FU CRM, RB CRM. |
| **Критерий включения** | Без единых справочников невозможно согласование данных. |
| **Проблемы качества** | Разные справочники в FU и RB; несинхронизированные значения; устаревшие коды; разные классификаторы. |

1.12. Операция / Платеж (Operation / Payment)
markdown
| Атрибут | Описание |
| :--- | :--- |
| **Описание** | Отдельная банковская операция или платежное поручение клиента. Отличается от транзакции тем, что может включать несколько транзакций (например, один платеж → списание со счета клиента и зачисление на счет получателя). |
| **Основные атрибуты** | ID операции, тип (входящий/исходящий платеж, перевод, пополнение), сумма, валюта, дата, статус, реквизиты плательщика/получателя, назначение платежа. |
| **Связи** | Связан с: Клиент (инициатор), Счет (списание/зачисление). |
| **Системы-источники** | FU Core, RB Core. |
| **Критерий включения** | Ключевая сущность для расчетов и отчетности. |
| **Проблемы качества** | Разные форматы платежей; несовпадение сумм; дублирование при миграции. |
