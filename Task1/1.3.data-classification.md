# Классификация данных

Классификация по типу, чувствительности и требованиям к защите (ПДн, банковская тайна, публичные данные).

| Сущность | Категория данных | Критичность | Влияние на ИБ | Средства защиты |
| :--- | :--- | :--- | :--- | :--- |
| Клиент | ПДн (персональные данные) | Высокая | Утечка нарушает 152-ФЗ, штрафы, репутационные потери | Шифрование хранилища, маскирование в интерфейсах, RBAC, аудит доступа, журналирование обращений |
| Счет | Финансовые данные + ПДн | Высокая | Утечка остатков и операций → финансовые риски, мошенничество | Шифрование, RBAC (доступ только по роли), аудит всех операций, разделение прав (операционист vs аналитик) |
| Карта | ПДн + Платежные данные | Высокая | Компрометация карточных данных → финансовые потери, фрод | Маскирование номера (токенизация), шифрование, строгий RBAC, двухфакторная аутентификация для критичных операций |
| Кредитный договор | Финансовые данные + ПДн | Высокая | Утечка кредитной истории, сумм → репутационные и финансовые риски | Шифрование, RBAC, аудит, ограничение доступа к просроченным договорам |
| Депозит | Финансовые данные + ПДн | Высокая | Утечка сумм и ставок → недоверие клиентов | Шифрование, RBAC, аудит |
| Транзакция | Финансовые данные + ПДн (косвенно) | Высокая | Утечка истории операций → анализ клиента без его согласия | Шифрование, RBAC (только для авторизованных ролей), аудит, разделение операционного и аналитического доступа |
| Обращение клиента | ПДн + Конфиденциальные данные | Средняя | Утечка истории обращений → репутационные риски | RBAC, маскирование, аудит |
| Сотрудник | ПДн + Данные о доступе | Высокая | Компрометация учетных записей → внутренний инцидент | RBAC, строгий контроль прав, двухфакторная аутентификация, аудит действий |
| Продукт | Справочные данные | Средняя | Несинхронизация тарифов → финансовые ошибки | Ограниченный доступ на изменение, версионирование |
| Справочник | Справочные данные | Средняя | Расхождения в классификаторах → ошибки отчетности | Версионирование, ограниченный доступ на изменение |
| Операция/Платеж | Финансовые данные + ПДн | Высокая | Утечка платежных реквизитов → мошенничество | Шифрование, RBAC, аудит |
