# Cutover-план для домена «Клиентские данные»

Переключение клиентских данных RetailBank на MDM Customer Hub и FU CRM. Выполняется в рамках
этапа 5 плана миграции (месяц 9–11).

| Шаг | Действие | Ответственный | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **1. Подготовка**<br>(за 2 недели до cutover) | Проверить готовность MDM Customer Hub. Убедиться, что cross-reference таблицы заполнены для 100% клиентов. Проверить CDC-потоки из FU CRM и RB CRM. Снять резервные копии клиентских данных обеих систем. | Data Office, Data Engineering | MDM готов к приёму 100% клиентов. CDC-потоки стабильны. Резервные копии сняты. |
| **2. Data Freeze**<br>(за 3 дня) | Объявить заморозку изменений клиентских данных в RB CRM — перевод в режим «только чтение». Все изменения вносятся в FU CRM. | Data Office | RB CRM не принимает новые изменения. |
| **3. Финальная выгрузка**<br>(за 1 день) | Выгрузить все клиентские записи из RB CRM (последний снимок). Загрузить их в MDM через Integration Layer. | Data Engineering | Все клиенты RB загружены в MDM. |
| **4. Загрузка** | После дедупликации в MDM золотые записи синхронизируются с FU CRM. Проверить, что все клиенты получили master_id. | Data Engineering, CRM Team | FU CRM содержит всех клиентов (FU + RB) с master_id. |
| **5. Сверка**<br>(в день cutover) | Сверить количество клиентов в RB CRM (до выгрузки) и в FU CRM (после загрузки). Сверить ключевые атрибуты (ФИО, ИНН, паспорт) по выборке 10% клиентов. | Data Office, QA | Расхождений нет. Атрибуты совпадают. |
| **6. Переключение потоков**<br>(час H) | Перенаправить все потоки, использующие RB CRM для чтения клиентов, на MDM и FU CRM. Отключить запись в RB CRM. | Integration Team | Все сервисы читают клиентов из MDM / FU CRM. |
| **7. Мониторинг**<br>(следующие 48 часов) | Отслеживать ошибки в потоках: lag в Kafka, ошибки в MDM. Мониторить обращения в поддержку по теме «не найден клиент». | Data Engineering, Support | Нет критических ошибок. Количество обращений в поддержку не выросло. |
| **8. Фолбэк**<br>(при ошибке) | Если в течение 2 часов обнаружены критические ошибки — более 5% клиентов не найдены, — включить обратный поток: читать клиентов из RB CRM (старый режим). | Data Engineering, DevOps | Откат выполнен. Система работает на старых потоках. |
