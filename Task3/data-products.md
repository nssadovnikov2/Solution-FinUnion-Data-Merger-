# Доменные data-продукты (подход Data Mesh)

Ниже предложены пять доменных data-продуктов, соответствующих бизнес-доменам банка и BIAN-областям.

| Data product | Домен (BIAN) | Основные данные | Владелец | Потребители |
| :--- | :--- | :--- | :--- | :--- |
| **Customer 360** | Party Data Management | Клиент, контакты, сегмент, согласия, master_id, cross-reference между FU и RB | Data Office / CRM-домен | CRM, BI, маркетинг, риск-менеджмент, контакт-центр |
| **Financial Transactions** | Transaction Management / Payment Execution | Транзакции, счета, остатки, обороты, комиссии | Финансовый департамент | BI, DWH, регуляторная отчётность, финансовый департамент |
| **Credit Portfolio** | Loan Management | Кредитные договоры, графики, просрочки, остатки задолженности, ставки | Кредитный бизнес (Risk) | BI, риск-менеджмент, регуляторная отчётность, коллекторы |
| **Customer Interactions** | Customer Interaction / Service Engagement | Обращения, чаты, звонки, визиты, категории, результаты | Контакт-центр | BI, маркетинг, качество обслуживания |
| **Card Operations** | Card Management | Карточные операции, статусы карт, лимиты, транзакции | Карточный бизнес | BI, антифрод, риск-менеджмент |

## Как Data Mesh применяется в архитектуре

1. **Децентрализованное владение.** Каждый бизнес-домен владеет своими данными и их качеством:
   Customer 360 — Data Office, Financial Transactions — финансовый департамент.
2. **Data-продукты как API.** Каждый data-продукт предоставляет данные через API (REST / gRPC) или
   через витрины в DWH и Lakehouse.
3. **Централизованный каталог (DataHub).** Все data-продукты зарегистрированы в DataHub с указанием
   владельцев, lineage, качества и SLA.
4. **Разделение ответственности.** Data Office владеет инфраструктурой (DWH, Lakehouse, DataHub),
   а бизнес-домены владеют содержанием data-продуктов.

Проектировать полноценный Data Mesh для всей организации в рамках задания не требуется — показано,
какие доменные наборы данных могут быть оформлены как data-продукты, кто ими владеет и кто их
использует.
