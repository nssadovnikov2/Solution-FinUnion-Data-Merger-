# Задание 3. Целевая архитектура данных и аналитическая платформа

**Кейс:** объединение FinUnion (FU) и RetailBank (RB) в FinUnion Group.

**Цель задания:** спроектировать целевую архитектуру данных объединённого банка — операционные
хранилища, аналитическую платформу, пайплайны данных, каталог данных и модель управления данными.

## Ключевое решение

**Гибридная архитектура: DWH (PostgreSQL) + Data Lakehouse (Iceberg + Trino).**

- **DWH** — источник истины для регламентированной, регуляторной и управленческой отчётности:
  строгая консистентность, воспроизводимость, привычный SQL.
- **Data Lakehouse** — исторические, событийные и полуструктурированные данные: карточные операции,
  события клиентских каналов, архивные выгрузки RB. Дешёвое хранение, горизонтальное
  масштабирование, time travel.
- **Data Mesh** применяется точечно — как доменные data-продукты поверх общей платформы,
  без децентрализации всей организации.
